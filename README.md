# 健身数据计算器

基于 Python（Tkinter + SQLite）制作的健身饮食计算工具，无需安装第三方库，Windows 自带 Python 即可运行。

## 运行方式

```bash
python main.py
```

首次运行会自动在同目录生成 `foods.db` 数据库并写入内置食物库。

## 功能

1. **基础代谢计算** —— 输入性别、年龄、身高、体重，用 Mifflin-St Jeor 公式计算每日基础代谢（BMR）。
2. **饮食热量计算** —— 可同时加入多种食物（选择食物 + 输入重量 g），自动汇总总热量与碳水、蛋白质、脂肪（g），点「确认记录」把本次清单写入数据库。
3. **食物管理** —— 手动录入食物的碳水 / 蛋白质 / 脂肪含量（按每 100 克填写），可点击列表载入修改、删除所选食物；保存时同名食物会覆盖更新。
4. **饮食结构计算**
   - **碳水渐降**：输入每日总热量，按热量占比 碳水:蛋白:脂肪 = 0.5:0.3:0.2 计算三大营养素克数。
   - **碳循环**：输入体重与碳水 / 蛋白质 / 脂肪三个体重倍数（g/kg），按每周 2 高碳日 + 3 中碳日 + 2 低碳日 计算每日与每周的碳水、蛋白质、脂肪及总热量。
5. **饮食记录** —— 记录页会列出所有记录过的日期，点击某天即可查看当天所有饮食记录与「本日总摄入量」（同一天多餐会自动汇总），可查看食物明细、删除记录；新增记录后日期列表自动更新。

## 碳循环的计算说明

输入的三个体重倍数（g/kg）代表「每日平均摄入」：

```
每日平均 = 倍数 × 体重
```

每周 2 高碳日 + 3 中碳日 + 2 低碳日，碳水与脂肪按固定比例分配到各天，蛋白质三种日恒定，使**一周总量精确等于 7 × 倍数 × 体重**：

- 碳水：高碳日 : 中碳日 : 低碳日 = 50% : 35% : 15%
- 脂肪：高碳日 : 中碳日 : 低碳日 = 15% : 35% : 50%

例：70kg、碳水 3g/kg → 每周碳水 = 7 × 3 × 70 = 1470g。

## 文件结构

- `main.py` —— 桌面版图形界面（Tkinter）
- `index.html` / `styles.css` / `app.js` —— 网页版（手机可用，PWA）
- `manifest.json` / `sw.js` / `icon-*.png` —— PWA 配置、离线缓存与图标
- `nutrition.py` —— 桌面版计算逻辑（网页版逻辑已内置于 `app.js`）
- `database.py` —— 桌面版 SQLite 数据库读写
- `foods.py` —— 内置默认食物库

## 打包发布

- **Windows 可执行文件**：`python -m PyInstaller --onefile --windowed --name FitnessCalculator main.py`，产物在 `dist/FitnessCalculator.exe`（数据保存在 exe 同目录的 `foods.db`）。

## 网页版（PWA，手机可安装）

网页版完全在浏览器本地运行，数据保存在浏览器 localStorage，可离线使用，并可「添加到主屏幕」像 App 一样使用。

- **本地预览**：在项目目录执行 `python -m http.server 8000`，浏览器打开 `http://localhost:8000`。
- **部署到手机**：把整个目录上传到任意静态托管（GitHub Pages / Netlify / Vercel 等），用手机浏览器打开 https 地址，点「添加到主屏幕」即可安装为 PWA。
  > 注意：PWA 的 Service Worker 需要 HTTPS（或 localhost）才生效，部署到手机时必须使用 https。
